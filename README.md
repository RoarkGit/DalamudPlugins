# DalamudPlugins

Shared plugin repository manifest (`pluginmaster.json`) for RoarkGit's Dalamud plugins.

## Adding this repository

In-game (or via `/xlsettings`): Settings -> Experimental -> Custom Plugin Repositories -> add

```
https://raw.githubusercontent.com/RoarkGit/DalamudPlugins/main/pluginmaster.json
```

then restart or refresh the plugin installer. Any plugins listed here will show up alongside the
official repository.
